# DESIGN_DNA: Soleyah Med Spa & Wellness concept

**One line:** a med spa that has not opened yet, so the site sells the founder and the arrival, not before and after photos.

| Choice | Decision | Why |
|---|---|---|
| Hero archetype | Type led headline beside a drawn rising sun (three arcs and a disc) with a rotated "2,000 square feet" stamp | No real photos exist yet (the live site uses stock), so the hero is type and drawing, never stock faces. |
| Display / body | Cormorant Garamond 500/600 + Jost 400/500/600 | Soft luxury serif, geometric sans. |
| Palette | `--cocoa` #3e1f14 and `--umber` #70402e (sampled from the Soleyah logo), `--clay` #c4876a, `--sand` #efe4d4, `--cream` #fbf7f1, `--lavender` #a99bc4 (the lavender towels) | |
| Signature | The sun arc (Sol in Soleyah): kicker icons, hero, timeline dots, footer sun, favicon | |
| Grid break | Home: the arrival ritual steps indent one by one. Story: the pull quote shifts right. | |
| Footer | Closing spread: "Opening in Sunset Valley, November 2026." under a setting sun | |

## What changes for production
Remove the concept banner, noindex and the robots Disallow, point BASE at the real domain, wire the form, replace placeholders, get photo permission, and add privacy, terms and accessibility pages (counsel review).
