# Soleyah Med Spa & Wellness: concept site by LuminArch

A pitch demo. **Not the official site.** Every page is noindex, robots.txt disallows all, and a concept banner sits on top.

- Live: https://soleyah-med-spa-demo.vercel.app/
- Stack: hand written static HTML, CSS and JS generated by `build.py` with `lib.py` (whe-fest pattern from the LuminArch style guide). Fonts self hosted in `fonts/`.
- Files: `css/design-system.css` (tokens), `css/components.css`, `css/pages.css`, `js/main.js`, `img/` (WebP), `DESIGN_DNA.md`, `FACTS_LOG.md`, `research/` (reference sites).

```
python3 build.py
python3 -m http.server 8000
```
Forms are demos and send nothing.
